# down-town 0.2.1

Released on 2026-09-02.

Patch on 0.2.0: social share preview and origin TLS for Cloudflare Full SSL.

## Highlights

- Landing share image for Open Graph and Twitter (`Frontend/public/og-image.jpg`).
- Root metadata uses `NEXT_PUBLIC_APP_URL` as `metadataBase` so crawlers get an absolute `og:image`.
- Traefik `websecure` Host routers with TLS on origin `:443`; HTTP `web` redirects to HTTPS.

- App manifest (`Frontend/package.json`): `1.6.4`
- Git tag: `v0.2.1`
