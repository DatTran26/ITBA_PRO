# down-town 0.1.0

Released on 2026-08-24.

This is the first public release of down-town. It ships the standalone Vision OCR module and the repository's GitFlow delivery safeguards.

## Highlights

- Extract text from uploaded images through `POST /api/ocr/scan`.
- Use Gemini Vision as the primary OCR engine with local Tesseract fallback.
- Upload images through a React and TypeScript scanner interface.
- Build the frontend reproducibly with Vite and Tailwind CSS.
- Run backend API and OCR service tests and a frontend rendering test.
- Keep the OCR module self-contained under `modules/vision-ocr`.

## Version

- Backend API: `0.1.0`
- Frontend module: `0.1.0`
- Git tag: `v0.1.0`

See the [Vision OCR module guide](../../modules/vision-ocr/README.md) for setup and usage.
