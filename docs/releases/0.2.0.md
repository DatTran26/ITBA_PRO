# down-town 0.2.0

Released on 2026-09-02.

This release ships the Town Hown application and VPS continuous delivery.
Vision OCR from 0.1.0 remains in `modules/vision-ocr`.

## Highlights

- Next.js app under `Frontend/` with Supabase schema in `Backend/`.
- GitHub Actions publishes `ghcr.io/dattran26/down-town` and deploys over SSH as `root`.
- `develop` → `/opt/ITBA-OCR/staging` (`staging.wpcteam.shop`, host port 2026).
- `main` → `/opt/ITBA-OCR/production` (`production.wpcteam.shop`, host port 2005).
- Runtime secrets stay in VPS `.env` files; GitHub Environments hold public `NEXT_PUBLIC_*` vars and deploy SSH keys.

## Version

- App manifest (`Frontend/package.json`): `1.6.4`
- Git tag: `v0.2.0`
