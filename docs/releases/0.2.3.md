# down-town 0.2.3

Released on 2026-09-17.

Runs the workplace Vision Python APIs on staging and production. 0.2.2 shipped
the Next.js dashboard for Face ID, behavior, and OCR, but VPS deploy only
recreated `web` and skipped sidecar images.

## Highlights

- GitHub Actions builds `linux/amd64` GHCR images for Vision AI (InsightFace +
  YOLO) and Vision OCR (Gemini + Tesseract + NĐ 30 export).
- `deploy/vps/remote-up.sh` pulls and starts `web`, `vision-ai-api`, and
  `vision-ocr-api`, then health-checks all three.
- Next.js OCR / NĐ 30 BFF routes use `VISION_OCR_URL` (Compose DNS) instead of
  `localhost:8000` inside the `web` container.
- Face ID sign-in allowlists `staging.wpcteam.shop` and
  `production.wpcteam.shop`, and reads `x-forwarded-host` behind Traefik.
- Brand logo replaces the text "AI" mark on landing, login, and the dashboard
  navbar.

YOLO `.pt`/`.onnx` weights stay off git. Copy them onto the VPS host under
`models/vision-ai/` and add `GEMINI_API_KEY` to the runtime `.env`. InsightFace
`buffalo_l` downloads on first Face ID use.
