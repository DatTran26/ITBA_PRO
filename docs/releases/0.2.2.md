# down-town 0.2.2

Released on 2026-09-17.

Promotes `develop` since 0.2.1 to production: AI provider settings, Face ID
re-authentication, privileged Edge Function auth, workplace Vision/OCR, and
recruitment reporting.

## Highlights

- System Settings stores OpenAI or Gemini keys as password fields; the UI
  masks them and server routes resolve provider/model/key with env fallback.
- Admins issue hashed Face ID re-authentication links. The token is claimed
  before enrollment so a revoked or in-flight link cannot clear the Face ID
  block.
- CV/topic/question Edge Functions require an internal JWT/role before using
  the service-role client. Settings RLS uses `is_internal_user()`.
- Dashboard workplace Vision (attendance, behavior, OCR studio) and
  recruitment Excel/KPI reporting land with this promotion.
- VPS deploy recreates only the GHCR `web` container (`docker compose up
  --no-deps`). Local Vision API images are not required on staging/production.
