Bảng orders có 40 triệu dòng. Truy vấn dưới đây chạy chậm. Cách xử lý nào hiệu quả nhất?

SELECT id, total, created_at
FROM orders
WHERE customer_id = $1
ORDER BY created_at DESC
LIMIT 20;
Tạo index trên (customer_id, created_at DESC)
